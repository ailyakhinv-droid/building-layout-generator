# Генератор застройки по ТЭП

Инструмент автоматизированной расстановки типовых жилых секций на земельном участке с соблюдением градостроительных нормативов и расчётом технико-экономических показателей (ТЭП).

## Возможности
- 📐 **Импорт участка**: поддержка прямоугольных участков и произвольных полигонов (координаты в локальных метрах / GeoJSON).
- 🏗️ **Библиотека секций**: поддержка типовых секций (рядовые, угловые, торцевые) с квартирографией и габаритами.
- ⚙️ **Алгоритм расстановки**: формирование зданий из цепочек секций вдоль основных осей участка с учётом пожарных и инсоляционных разрывов.
- 📊 **Автоматический расчёт ТЭП**:
  - Площадь застройки (BCR), плотность застройки (FAR, КЗ);
  - Общая площадь (GFA), жилая площадь;
  - Сводная квартирография (1к, 2к, 3к);
  - Расчётное население, нормативные парковочные места, площадь озеленения.
- 🎯 **Режимы генерации**:
  1. Фиксированная этажность.
  2. Подбор под целевые ТЭП (целевой FAR, кол-во квартир, GFA).
  3. Максимизация жилой площади с контролем ограничений.
- 🗺️ **Визуализация и экспорт**:
  - Графический 2D-генплан (Matplotlib) с дифференциацией секций и легендой;
  - Векторная интерактивная карта OSM (Leaflet 2D);
  - Интерактивная 3D-модель застройки на WebGL / MapLibre GL JS с реальной высотой секций, карточками ТЭП и фильтрами;
  - Экспорт в GeoJSON, текстовые отчёты и автономные 3D HTML-файлы.
- 🖥️ **Интерактивный UI**: веб-приложение на Streamlit.

## Структура проекта

```text
├── app/
│   └── streamlit_app.py       # Веб-интерфейс на Streamlit (2D/3D визуализация)
├── config/
│   ├── defaults.yaml          # Градостроительные нормативы по умолчанию
│   └── sections/              # Каталог типовых секций (JSON)
├── src/
│   ├── models/                # Модели данных (Site, SectionType, Building, TEP)
│   ├── core/                  # Геометрия, расстановка, калькулятор ТЭП, оптимизатор
│   ├── library/               # Управление библиотекой секций
│   ├── visualization/         # Отрисовка планов (Matplotlib 2D, Leaflet OSM, MapLibre 3D)
│   └── export/                # Экспорт в GeoJSON, текстовые отчёты и автономный 3D HTML
├── test_run.py                # Консольный тестовый скрипт
├── test_3d_viewer.py          # Тест генератора 3D-визуализации MapLibre GL
└── requirements.txt           # Зависимости Python
```

## Быстрый старт

### 1. Активация виртуального окружения
```powershell
.\.venv\Scripts\Activate.ps1
```

*(Если окружение ещё не создано)*:
```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 2. Запуск веб-приложения (Streamlit)
```powershell
streamlit run app/streamlit_app.py
```
или без активации:
```powershell
.\.venv\Scripts\streamlit.exe run app/streamlit_app.py
```

### 3. Запуск консольного теста
```powershell
python -X utf8 test_run.py
```
